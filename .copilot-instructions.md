# Copilot Coding Agent Instructions

## Project context
- This repository is an Obsidian plugin written in TypeScript.
- Chronotyper tracks note edit time and writes metadata updates.

## Build and validation
- Install dependencies: `npm install`
- Build (includes TypeScript type-check): `npm run build`
- Development build/watch: `npm run dev`

## Implementation guidelines
- Keep changes small and focused.
- Follow existing architecture boundaries (core, managers, storage, event handlers).
- Prefer early returns over deep nesting.
- Use existing error handling patterns (for example `ChronotyperError`) when adding plugin-facing errors.

## Release/version note
- Keep `manifest.json` and `package.json` versions aligned when changing releases.
